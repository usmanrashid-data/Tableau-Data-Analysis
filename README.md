# 📊 Tableau Data Visualisation Project | Data Technician Bootcamp

## 🚀 Overview

This project was completed during a Data Technician Bootcamp and showcases the use of Tableau for interactive data analysis, dashboard development, and data storytelling.

Working with global health and Spotify datasets, I created visualisations that transformed raw data into meaningful insights using a variety of chart types, filters, and calculated fields.

The aim of the project was to explore trends, identify patterns, and communicate key findings through visually engaging and interactive dashboards.

## 🎯 Project Highlights

### 🌍 Global Health Dashboard

Analysed worldwide health data to identify patterns in life expectancy, population demographics, and health indicators across different continents and countries.

Key dashboard features included:

* Average life expectancy by continent
* Life expectancy trends over time
* Population distribution by gender
* BMI versus life expectancy comparisons
* Interactive country filtering

### 🎵 Spotify Trends Dashboard

Analysed Spotify music data to identify trends in popularity, genre performance, and listener preferences.

Key dashboard features included:

* Popularity by genre
* Comparison of music characteristics
* Genre performance analysis
* Interactive dashboard navigation
* Filter-driven data exploration
